vips-static editor demo

Headless WebGL preview of the ordered edit list. The canvas shows exactly what the VIPS side renders for the same JSON (modulo 8-bit rounding on GPUs without float render targets).

Feed it to the CLI, e.g. echo '{"cmd":"convert","input":"in.jpg","output":"out.jpg","edits":<edits>}' | vips-preview 3>info.json (open info.json on fd 3). Thumbnails accept "edits" too; edits run after resize, so blur/sharpen radii are output pixels.
